# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc] as its code of conduct. In short: be respectful and constructive; harassment, discrimination and abusive behaviour are not tolerated.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

Report unacceptable behaviour privately to the maintainer, Oscar Diaz <odiaz@ieee.org>. All complaints will be reviewed and investigated promptly and fairly, and the privacy and security of the reporter will be respected.
